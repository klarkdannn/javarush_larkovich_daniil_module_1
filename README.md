## Алфавит и ключ

В алфавите 33 буквы русского алфавита (включая ё, й, ю), знаки пунктуации . , « » " ' : ! ? и пробел, всего 43 символа. Порядок не меняется. Ключ — целое число от 0 до 42. Сдвиг идёт по кругу, поэтому выход за границы алфавита невозможен. Регистр сохраняется: заглавные буквы остаются заглавными. Символы, которых нет в алфавите (латиница, цифры, перенос строки, табуляция и т.п.), при шифровании и расшифровке не меняются, поэтому многострочный текст обрабатывается корректно.

## Как работают методы

Класс Cipher в конструкторе принимает массив символов алфавита и строит по нему HashMap, где ключ — символ, значение — его позиция. Так позиция символа ищется за одно обращение к карте, а не перебором всего массива. Методы encrypt и decrypt вызывают общий приватный process, только decrypt передаёт сдвиг с минусом. Внутри process идёт цикл по символам текста: запоминается, заглавный символ или нет, символ приводится к нижнему регистру и ищется в карте. Если символа в карте нет, он возвращается как был. Если есть, новая позиция считается через Math.floorMod от суммы старой позиции и сдвига по длине алфавита — так получается корректный положительный индекс даже при отрицательном сдвиге. Берётся символ с новой позиции, и если исходный был заглавным, приводится к верхнему регистру. Поэтому текст после шифрования и расшифровки тем же ключом совпадает с исходником, включая регистр.

Класс Validator проверяет входные данные. Метод isValidKey возвращает true, только если ключ не меньше нуля и меньше длины алфавита. Метод isFileExists проверяет, что путь не пустой, файл существует и это именно файл, а не папка.

Класс FileManager отвечает за работу с файлами. Метод readFile читает весь файл через Files.readString с кодировкой UTF-8. Метод writeFile записывает строку через Files.writeString с опциями создания и перезаписи. Любая ошибка ввода-вывода перехватывается и превращается в CipherException с понятным сообщением, где указан путь и причина. Исходный файл никогда не открывается на запись.

Класс MainApp содержит меню и логику режимов. В полях создаются Scanner, FileManager, Validator, Cipher и BruteForce. Метод run запускает бесконечный цикл с меню из четырёх пунктов: шифрование, расшифровка с ключом, brute force, выход. Каждый режим — отдельный метод. В каждом режиме сначала спрашивается исходный файл в цикле, пока validator.isFileExists не вернёт true. Потом спрашивается выходной файл: проверяется, что это не тот же файл, что исходник (через Files.isSameFile), и что папка для него существует. Потом спрашивается ключ в цикле: если ввести буквы, Integer.parseInt бросит NumberFormatException, программа покажет сообщение «Ключ должен быть целым числом» и спросит заново. Если ввести число вне диапазона, validator.isValidKey вернёт false, программа покажет допустимый диапазон и спросит заново. Все CipherException ловятся в run и печатаются как «Ошибка: …», программа продолжает работу. На любом шаге можно ввести exit или выход, чтобы вернуться в главное меню.

Класс BruteForce реализует взлом. Метод decryptByBruteForce создаёт один Cipher на весь цикл и перебирает ключи от 0 до длины алфавита минус один включительно. Начинает с нуля, потому что ключ 0 тоже валиден и текст при нём не меняется. Для каждого ключа вызывает cipher.decrypt, ловит CipherException и переходит к следующему ключу. Полученный вариант оценивается тремя вспомогательными методами. Первый считает пунктуацию: для каждого знака точки, запятой, восклицательного, вопросительного, двоеточия и точки с запятой проверяет следующий символ — если там пробел, плюс три, иначе минус два. Второй считает длину слов: текст разбивается по пробелам, каждое слово длиной от 1 до 12 даёт плюс один, каждое слово длиннее 20 даёт минус пять. Третий считает частые короткие слова из заранее заданного множества (и, в, не, на, что, с, по, это, как, к, у, из, за, от, а, же, ли, о), каждое вхождение даёт плюс два. Итоговая оценка — сумма трёх. Лучший вариант по оценке запоминается и возвращается. Найденный ключ печатается в консоль, чтобы было видно, что перебор действительно работал.

Класс CipherException — это checked-исключение с двумя конструкторами: с сообщением и с сообщением плюс причиной. Используется везде, где нужно сообщить пользователю об ошибке без падения программы.
